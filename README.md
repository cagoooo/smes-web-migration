# 校網遷移與 AA 無障礙實作操作台

這是給各校資訊組長使用的**去識別化、跨校通用版**校網遷移與無障礙 AA 實作指南。
內容中的校名、網址、頁數、案件狀態與檔案素材都不代表任何單一學校，請替換成你校自己的資料。

👉 **[線上開啟操作台](https://cagoooo.github.io/school-web-migration-playbook/)**

📖 **[完整實戰故事集](./migration-story.html)**：保留常見失敗、證據邊界與可重做的查錯方法，不公開個案識別資訊。

## 給第一次來的資訊組長

請先開啟線上操作台，在最上方依目前情境選入口：

1. **剛開始搬站**：依 12 個步驟盤點內容、處室、附件與共用區塊。
2. **已切到正式新站**：先確認正式站、準備站與舊站的角色，不要只看外觀判斷同步。
3. **要跑 FreeGo**：只輸入你校正式新站網址，記錄日期、頁數、逾時與違規代碼。
4. **要申請 AA**：依你校實際頁面填寫自我評量；「待指派」只是等待官方分案，不是標章已核發。
5. **舊站要 HTTPS**：把 DNS、轉址、TLS 與憑證另開工作線，不和新站 AA 混在一起。

遇到問題時，在「快速查詢」輸入 `FreeGo`、`DNS`、`憑證`、`對比度`、`待指派` 或 `成員`，
即可篩選操作步驟與查錯卡。每張查錯卡都會說明先判斷什麼、不要誤做什麼，以及下一步應留下什麼證據。

## 使用前先替換的佔位符

公開版會使用以下文字，避免把某校設定誤當成通用答案：

- `<正式新站網址>`：你校真正要送 AA 的正式網址。
- `<共構準備站網址>`：建置或比對用的暫時網址。
- `<舊站網址>`：若要保留舊站，另行處理 HTTPS 的網址。
- `你校正式校名`、`你校機關代碼`、`你校頁數與報告日期`：全部依實際資料填寫。

## 核心判斷原則

- FreeGo 自動檢測、官方人工審查與 AA 標章核發是三個階段，不能混寫成「已取得標章」。
- 本機對比度工具是找線索；是否修正要以正式 FreeGo 或人工審查明確指出的問題為準。
- 準備站與正式站即使外觀相同，也不能直接視為同步；報告必須附網址、日期與範圍。
- 公開版只提供格式與流程；姓名、Email、電話、帳密、案件編號與校內素材必須留在校內安全位置。
- 若使用列出的教育局共構平台（此處僅作官方文件範例），可參考[官方總目錄](https://schoolweb.tyc.edu.tw/modules/tad_book3/index.php?op=list_docs&tbsn=1)、
  [申請流程說明](https://schoolweb.tyc.edu.tw/modules/tad_book3/page.php?tbsn=1&tbdsn=67)與
  [自我評量說明](https://schoolweb.tyc.edu.tw/modules/tad_book3/page.php?tbsn=1&tbdsn=68)。
  其他縣市或平台請換成所在地主管機關的官方文件。

## 公開版與校內版的分工

本 repository 只放去識別化的教學頁面與通用資產，適合分享、觀摩與查錯。
校內完整版仍留在原專案，才包含各校自己的區塊草稿、附件清單、內容素材與成員批次資料。

若你要把這套流程套到自己的學校，建議先複製操作台的 12 步驟，再建立一份只存於校內的工作資料夾，
不要直接把教職員名單或後台匯出檔貼進公開 repository。

## 授權與來源

內容依公開的教育主管機關教材、共構平台說明與無障礙申請流程整理，供各校參考；
正式申請、審查與標章核發仍以所在地主管機關與數位發展部最新公告為準。
